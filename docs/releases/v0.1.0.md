# ShouldaUsedThat v0.1.0

The first public release turns an explicit OSS need into a reproducible chain of discovery,
filtering, local saving, decision, revalidation, and adoption-planning receipts.

Highlights:

- deterministic hard gates, filters, JMESPath queries, stable ordering, and RFC 8785 identities;
- fixture, GitHub stars, GitHub search, and exact-repository read sources through the official
  `gh` CLI;
- profile-scoped private state outside repositories, immutable receipts, and last-known-good
  preservation;
- JSON authority with validated YAML, Markdown, table, and JSON Schema views; and
- a multi-platform test matrix, dependency/source/workflow/posture checks, runtime SBOM,
  checksums, and GitHub artifact attestations.

This release deliberately has no GitHub mutation executor, target-repository write path, runtime
model dependency, scheduler, hosted service, or PyPI publication. `apply` and `verify` fail closed.

# ShouldaUsedThat v0.4.0

This release turns the evidence corpus into a useful build decision. Start with a concrete software
problem and see what to use, try, learn from, study, watch, skip, or build—plus the exact custom
scope that remains.

## What changed

- Five reviewed build decisions now expose 17 problem-specific candidate actions instead of
  presenting a repository-first catalog.
- The homepage demonstrates a complete answer: reuse established quality-gate tools and keep only
  repository-specific policy custom.
- Decision cards show each project's contribution, caution, evidence, and reconsideration trigger.
- The complete 222-record screened corpus remains available as canonical JSON, while only assessed
  candidates receive rich evidence pages.
- The ordinary CLI journey is now `check → inspect → remember → recheck`; catalog publication
  and additive GitHub curation live under explicit `catalog` and `github` groups.
- Research orchestration is separated from maintainer publication and mutation services.

## Compatibility

This is a pre-1.0 minor release because it deliberately retires the `saved` and `used` creation
flows and the legacy List-preview planner. Existing save, preview, and adoption-plan JSON is not
rewritten or deleted; it remains inspectable through `shoulda_used_that.legacy` and the immutable
v0.3.0 schemas.

## Install

Python 3.12–3.14 and `uv` are required:

```console
uv tool install https://github.com/pradeeptathineni/shoulda-used-that/releases/download/v0.4.0/shoulda_used_that-0.4.0-py3-none-any.whl
shoulda --help
```

PyPI remains intentionally unused.

## Safety boundary

The deterministic and mutation boundaries are unchanged. `check`, `inspect`, `remember`,
`recheck`, `catalog`, and `github plan` cannot write to a target or mutate GitHub. `github apply`
accepts only an approved, unexpired, exact-fingerprint `github-curation` plan for the exact account
in an interactive terminal. It can only create a public List, add a star, or add membership while
preserving current memberships. Independent readback remains mandatory.
